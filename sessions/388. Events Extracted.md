## Front-loaded decisions (drafted at 387 close — review at prompt review; reopen only what the Open Gate flags)

1. **Names:** repo `crm-plugin--events` (the established pattern; handle `events`); first tag `v0.1.0`; require stays bound `^0.1`; package name `nonprofitcrm/events` unchanged. Repo owner-created, public, empty, sibling checkout — confirmed at the Open Gate.
2. **The testsuite travels with the package; core CI keeps running it via the vendor path.** The `Events` phpunit testsuite re-points `plugins/Events/tests` → `vendor/nonprofitcrm/events/tests`. Rationale: 383 deliberately moved these 29 files *into* the plugin (normative rule 5's target posture); moving them back to core at extraction would reverse that. The vendor-path testsuite keeps every test running in core CI unchanged (the "central build runs the distribution's plugin suites" disposition, plan § 6.3, made real) while the files ship with the package. Per-plugin CI in the plugin repo stays D11. `DistributionManifestGuardTest`'s testsuite assertion only scans `plugins/` suites — no edit needed there.
3. **Root `"Plugins\": "plugins/"` PSR-4 stays** even though `plugins/` empties: D3's carve refills it (per-vertical blocks carve into `plugins/` first), and the mapping's retirement is D12 endgame work. The empty directory itself may vanish from git (git tracks no empty dirs) — that's fine and expected.
4. **Guard relaxation scope (survey item 6):** the in-repo path-package assertion becomes conditional on in-repo packages existing; no other guard content changes. The vanish/behavior nets pass with assertions unchanged.
5. **No dependency move** — Events requires `php` only; the 387 stripe pattern is not exercised this session.
6. **Contract doc at close: 0.11.0 → 0.12.0.** External repo section gains the third consumer (first migration-owning + testsuite-carrying extraction); the testsuite posture recorded (vendor-path suite, core CI runs it, D11 unchanged); runbook deltas folded (fixture migrator re-point, baseline-key re-point, empty-`plugins/` note, gate 4 worked-example lines for a multi-widget plugin); changelog.
